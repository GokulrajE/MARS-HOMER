# MARS-HOMER

The unified application is [Godot/project.godot](Godot/project.godot). It contains eleven games, clinical-record workflows, a Windows serial bridge, shared 60-second trials and adaptive difficulty.

Run the portable build at `dist/MARS_HOMER/MARS_HOMER.exe`, or open the Godot project in Godot 4.6.2 and press F5.

See [setup and use](Godot/README.md) and [validation boundaries](Godot/MIGRATION.md). Software tests run in simulation; physical robot operation and production uploads still require validation with the connected device and live services.

The unified Godot project also includes day/evening/night lighting across trials and rotating obstacle or target appearances for all ten games. See `Godot/README.md` for behaviour and validation details.
