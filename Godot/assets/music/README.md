# Original Character Flight themes
Six original synthesized mono 22050Hz / 16-bit PCM loops, created for this project using additive sine harmonics, short envelopes, gentle bass and synthesized percussion. No sampled commercial recordings, actor voices or existing theme melodies.

Bheem 96 BPM plucked melody; Chutki 80 BPM bell-like melody; Raju 112 BPM wood-like plucks; Mr Bean 92 BPM comic pizzicato; Rajini 88 BPM warm bass; Vijay 108 BPM bright synth. Each loop is 32 beats, with wrapped note tails. Godot uses uncompressed PCM import for sample-accurate loop points.

Playback is intentionally quiet by default, with persistent user volume and mute controls. Audio pauses on hold and stops on completion.
